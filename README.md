# Stock Market Intelligence Dashboard

## Overview
This project analyzes Reliance Industries stock data using Python and Yahoo Finance.

## Features
- Historical Stock Analysis
- Daily Return Calculation
- 50-Day Moving Average
- Trend Visualization

## Technologies Used
- Python
- Pandas
- Matplotlib
- yFinance
- Jupyter Notebook
